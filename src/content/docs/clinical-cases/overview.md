# 臨床案例

本區收錄 **case report 與 case series**，並依臨床問題與 diagnostic phenotype 整理，而不是依疾病名稱或預設結論分類。

## 收錄範圍

- Case report
- Case series
- Diagnostic overlap / mimic
- Discordant findings
- Unusual phenotype
- 特殊年齡、基因型或影像表現的已發表病例

## Hypertrophic phenotype

收錄 cardiac amyloidosis 與 hypertrophic cardiomyopathy phenotype **重疊、模仿或共存** 的案例。

- [Cardiac amyloidosis with LVOT obstruction](../lvot-obstruction/)

## 預計整理的案例主題

- HCM and ATTR coexistence
- Early-onset ATTR phenotype
- Genetic variants
- Discordant scintigraphy and biopsy
- ATTR and alternative causes of LV hypertrophy

## 與「研究與文獻」的區分

本區著重「**這個病人／這組病例怎麼呈現、怎麼被診斷**」。

若文獻主要回答的是族群層級的研究問題，例如 prevalence、screening yield、diagnostic performance、treatment outcome、registry 或 observational study，則歸入「研究與文獻」。

Guideline / consensus 則獨立放在「指引與共識」。
