## Evidence categories

The literature index will separate evidence by study type:

- Guideline / consensus
- Randomized clinical trial
- Original observational research
- Case series
- Case report
- Conference abstract

## Editorial standard

Each summary should contain the clinical question, population, methods, key findings, limitations and a direct link to the original source. Conference abstracts will be labeled separately from peer-reviewed full publications.
