# ATTR-CM Clinical Resource

Evidence-based clinical resource for transthyretin amyloid cardiomyopathy.

## Purpose

This repository contains the public website only. Do **not** place private notes, physician interaction records, patient information, internal business materials, or private Notion exports in this repository.

## Local development

```bash
npm install
npm run dev
```

## Deployment

The site is configured for GitHub Pages at:

`https://yuhsin514.github.io/attr-cm-clinical-resource/`

Deployment is handled by `.github/workflows/deploy.yml` after GitHub Pages is set to **GitHub Actions**.
