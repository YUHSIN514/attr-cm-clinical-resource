# Taiwan｜V142I hereditary ATTR-CM

**2024｜*Acta Cardiologica Sinica***  
*Hereditary Transthyretin Amyloid Cardiomyopathy with Val142Ile Mutation in Taiwan: A Case Report*

台灣發表的 hereditary ATTR-CM case report；PYP scintigraphy 呈 Grade 3 myocardial uptake，後續 genetic testing 發現 **TTR Val142Ile（V142I）** variant。
